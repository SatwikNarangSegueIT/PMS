# PMS — Pharmacy Management System (Frontend)

Frontend for an enterprise pharmacy management system: Dispense, POS, Office, HQ, Admin.

**Stack:** Next.js (App Router), TypeScript, TanStack Query, Zustand, Orval, Tailwind CSS, shadcn/ui.

The backend (NestJS) is in a separate repository. Its API reaches this repo through the OpenAPI spec in `openapi/`, which Orval turns into typed hooks.

See **[STRUCTURE.md](./STRUCTURE.md)** for the folder layout and its rules.
